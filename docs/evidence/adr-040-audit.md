## C. Schema changes required by ADR-040

- `ChatHistoryEntry`: remove canonical event sequence semantics; after visibility and `ChatMessageSchema` parsing/filtering, assign page-local ordinals. `ChatHistory` frame is class (b), current viewer cursor, with window/page cap using the active-membership eligibility predicate.
- `StateSyncAck`: replace strict `{ seq }` payload with strict `{ bindingEpoch, generation, seq }`; `StateSync` carries the same triple. Validate acknowledgement against server-bound seat and exact baseline sent on that socket; recovery uses authoritative StateSync.
- `PresenceChanged`: currently requires `seq`; class (a), advance once per visible logical update, transmit seat-local cursor.
- `Error`: currently requires `seq`; class (b), current seat cursor, never advances.
- `SeatResumeChallenge`: currently has `seq: 0`; pre-baseline, explicitly cursor-less and must not initialize/advance stream.
