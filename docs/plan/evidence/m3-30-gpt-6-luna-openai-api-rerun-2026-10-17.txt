Compatibility adjustments and limitations:
- The unmodified OpenAI-compatible adapter sends `max_tokens` and temperature 0 for moderation. GPT-6-Luna rejected `max_tokens` (it requires `max_completion_tokens`) and rejected any `temperature` value.
- A temporary local HTTP proxy translated `max_tokens` to `max_completion_tokens` and omitted `temperature`. Thus moderation used provider-default temperature, not deterministic temperature 0; this is not directly adapter-equivalent.
- The 8-token narration warmup exhausted its completion budget without emitting text. The temporary probe copy raised only the unmeasured warmup budget to 128 and did not require warmup text. Measured narration requests retained the 512-token harness budget.
- Prompt caching was provider-managed and not independently disabled or verified. Additional API preflight and compatibility diagnostics, plus warmups, are excluded from N=30.
- First-visible clock starts at narration-model request, not player submit. No WebSocket acknowledgement, DB/session overhead, per-model TTFT/total split, per-gate-call durations, tool loop, or real user prompt distribution was measured.
