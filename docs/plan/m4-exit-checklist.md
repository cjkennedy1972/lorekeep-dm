## Recorded decisions

- **2026-10-26 — One DM narration per resolved turn.** A combat move alone does not narrate. Narration starts when the turn resolves (for example on `end-turn`, or on timer expiry). This is by design under ADR-033 §6.3 (card `1e8755b3`, confirmed). The #337 evidence report raised this as an open question; this decision answers it.
- **2026-10-26 — `KickSeat` is the host seat-removal path.** The product has no separate "revoke" command. The host sends `KickSeat` (`packages/schema/src/ws.ts`), routed in `apps/server/src/gateway/ws.ts` to `room.kickSeat`. The removed seat's socket closes with 1008 and the seat's access is revoked (`SeatRevoked`, cause `host-kick`). Gate 1 scenarios for "host revoke" exercise this path (see #352).

## Balance and spotlight note (9a)

The "six PCs vs two goblins ends in party defeat in 4–8 rounds" claim from the #337 evidence did not reproduce. Triage in [#338](https://github.com/cjkennedy1972/lorekeep-dm/pull/338) (merged, `44e7036`; card `90bddedb`, done) found the defeat is caused by the test driver, not by level-1 balance. The spotlight loop in `sim-combat.test.ts` sends only `end-turn` for PC seats, so PCs never attack. Idle-PC runs ended at rounds 15–23. Engine finding: goblin hits were recorded as `slashing` while the catalog says `piercing`. [#345](https://github.com/cjkennedy1972/lorekeep-dm/pull/345) fixes this by resolving the attack from the catalog. The triage's recommended test-driver fix (PCs attack in the spotlight loop) is not on `main`. Balance for a real six-PC build is still not established, because the fixture hard-codes PC AC and attack.
